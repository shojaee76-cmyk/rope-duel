# THE ROPE DUEL (rope-duel)

## What it is
A single-page site: two Andalusian cats (DON GATO = BUY pressure, gold; SULTAN BIGOTES = SELL pressure, jade) duel with swords on a suspended rope in a moonlit courtyard. The fight is driven by the live Binance BTC/USDT tape: 30s rolling order-flow pressure pushes attacks/parries, the rope flag shows live price + 24h change, whales trigger callouts, crowd cheers the winning side. Falls back to a SIMULATION tape (orange badge) when Binance is unreachable, so the page always works.

## Architecture
- `feed.js` — BtcTradeFeed: Binance WS (trade + ticker), 30s rolling pressure [-1,+1], 250ms throttled emits, 3-endpoint reconnect w/ backoff, deterministic sim fallback. Zero deps.
- `src/scene.js` — `createDuelScene(container, {demo, debug})`: verlet rope, 10 signature/combat states, blade-lock + clash adjudication, hit reels, price flag, VFX, crowd. three r186 (vendored in repo; bundled into bundle.js locally).
- `src/tex.js` — procedural texture factory: fur (patches / irregular tabby), cloth weave, brushed metal, leather, stone ashlar, braided hemp. Each returns `{map, bump[, rough]}`; every texture gets mipmaps + anisotropy.
- `src/director.js` — fight director: pair locomotion (circle → engage → break), tempo clock, move table + cooldowns, lock/clash/hit resolution.
- `main.js` + `feed-adapter.js` — integration boot: feed onChange payload -> scene API + HUD.
- `index.html` — HUD, pressure meter, whale callouts, connection badge. Only 3 runtime files needed: index.html + feed.js + bundle.js (classic IIFE, works over file://).
- `tools/` — verification harness: `errcheck.mjs` (boot errors), `probe.mjs` (30s fight/rope/perf telemetry), `ropelab.mjs` (rope geometry + isolated render + texture-vs-flat detail), `ropegone.mjs` (frozen-frame A/B: are the rope pixels there), `shot.mjs` (screenshots at real combat beats), `livecheck.mjs` (deployed build: hash match, errors, live-tape fight stats), `eyes.py` (OpenRouter vision art-director pass).

- 2026-09-14 (v4): user reported the background "shaky". Diagnosed with a **temporal stability probe** (`stab.mjs`: 8 screenshots 90ms apart, mean |delta| per screen region between consecutive frames) instead of guessing. Baseline: sky 0.21 (frozen) but wall **20.0**, dado 15.8, floor 5.3 -> the background was changing almost as much as the fighting cats, while the camera itself was static. An amplified frame-difference map showed the character of the change was: solid silhouettes (cats, expected), particle dots (ambience) and **fine speckle along static patterns** (arch rings, star panels, floor grid, medallion rim) plus a uniform region glow = **lighting flicker**. Fixes, all measured: (1) torch lights strobed 1-4 Hz at +-40% of intensity and were pumping the whole wall => now slow shallow breathing (13 +-1.5, 0.9-3.1 rad/s); (2) **shadow map disabled again** - it cost ~40% of the frame budget and its per-frame re-render speckled the floor (the only receiver) => floor 5.3 -> 0.76, FPS 45 -> 93; (3) new `src/tex.js` central texture factory: mipmaps + `anisotropy = min(8, maxAniso)` on EVERY canvas texture, handed the renderer's max via `setMaxAnisotropy()` before any texture is built; (4) softened the hard-edged fine patterns that crawled (floor grout 3px solid -> 2.5px @0.66 alpha, medallion/azulejo star edges blurred 0.45/0.35px via ctx.filter); (5) camera: the fighter-follow pan is now low-passed (a stumble teleports a cat 0.5 units and used to snap the whole frame with it), mouse parallax got a 0.07 dead zone + slower easing, idle drift halved; (6) rim lights' throw shortened (44/9 -> 34/7) so swinging with the cats cannot pump the back wall; (7) fewer/slower/dimmer ambience particles (fireflies 70 -> 44, embers 46 -> 28, slower blink/rise) because at close range their blinking read as instability. Result: wall 20.0 -> **6.19** (-69%), floor 0.76, sky 0.03, FPS 93.
