# THE ROPE DUEL (rope-duel)

## What it is
A single-page site: two Andalusian cats (DON GATO = BUY pressure, green; SULTAN BIGOTES = SELL pressure, red) duel with swords on a suspended rope in a moonlit courtyard. The fight is driven by a live BTC/USDT tape from a public exchange WebSocket: 30s rolling order-flow pressure pushes attacks/parries, the rope flag shows live price + 24h change, whales trigger callouts, crowd cheers the winning side, and a 1s candlestick panel is embedded in the arena. The feed is MULTI-PROVIDER (Binance first, Bybit as the geo-reachable fallback) and the HUD names the one in use (`LIVE · BINANCE` / `LIVE · BYBIT`). Falls back to a SIMULATION tape (orange badge) only when no provider is reachable, so the page always works.

## Architecture
- `feed.js` — BtcTradeFeed: Binance WS (trade + ticker), 30s rolling pressure [-1,+1], 250ms throttled emits, 3-endpoint reconnect w/ backoff, deterministic sim fallback. Zero deps.
- `src/scene.js` — `createDuelScene(container, {demo, debug})`: verlet rope, 10 signature/combat states, blade-lock + clash adjudication, hit reels, price flag, VFX, crowd. three r186 (vendored in repo; bundled into bundle.js locally).
- `src/tex.js` — procedural texture factory: fur (patches / irregular tabby), cloth weave, brushed metal, leather, stone ashlar, braided hemp. Each returns `{map, bump[, rough]}`; every texture gets mipmaps + anisotropy.
- `src/director.js` — fight director: pair locomotion (circle → engage → break), tempo clock, move table + cooldowns, lock/clash/hit resolution.
- `main.js` + `feed-adapter.js` — integration boot: feed onChange payload -> scene API + HUD.
- `index.html` — HUD, pressure meter, whale callouts, connection badge. Only 3 runtime files needed: index.html + feed.js + bundle.js (classic IIFE, works over file://).
- `tools/` — verification harness: `errcheck.mjs` (boot errors), `probe.mjs` (30s fight/rope/perf telemetry), `ropelab.mjs` (rope geometry + isolated render + texture-vs-flat detail), `ropegone.mjs` (frozen-frame A/B: are the rope pixels there), `shot.mjs` (screenshots at real combat beats), `livecheck.mjs` (deployed build: hash match, errors, live-tape fight stats), `eyes.py` (OpenRouter vision art-director pass).
